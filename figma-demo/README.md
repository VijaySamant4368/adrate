# AdRate React App

This folder contains a React + Tailwind implementation of the AdRate concept with a mock login, home feed, business dashboard, ad upload flow, active campaigns, analytics, and brand page.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- The app is fully client-side and stores the mock session in localStorage.
- The UI is responsive and keeps the same dark visual language across all sections.
